# 证据规则

## 什么算证据

只有两类来源能支撑一条 Candidate 事实：

1. 用户上传的材料（简历、项目说明、作品集等），可定位到原文引用与位置。
2. 用户在对话中的明确陈述。

**不算证据**：模型推断、助手自己说过的话、岗位要求、行业常识、聚合站推断。

## 三类高 claims 的核对方式

| 类型 | 核对方式 |
| --- | --- |
| 技术 | 该技术在哪个项目/经历里出现过？能否给出 `fact_id` 或原文引用？ |
| 数字 | 这个数字来自材料还是估算？材料里有没有同一量级的上下文？ |
| 成果 | 有没有奖项名、名次、上线时间、链接等可核验信息？ |

## 判定

- 有来源 → 可以复述，并附上 `fact_id` 或 quote。
- 无来源 → 标为待核实，**不能复述为事实，也不能替它补一个合理数字**。
- 相互冲突 → 都列出来让用户确认，不自动覆盖。

## 失败要如实说

检索工具报错、材料读取不完整、解析状态是 partial 时：

- 明确说"只依据已读取部分"或"检索未完成"；
- 不把失败写成"已完成诊断"；
- 不因为拿不到证据就默认用户"大概有"或"大概没有"。
