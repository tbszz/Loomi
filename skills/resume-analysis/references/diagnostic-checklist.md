# 诊断检查清单

按严重度从高到低过一遍。每条都要能在 Candidate 原文里找到落点，找不到就写成"待核实"。

## A. 站不住的说法（最高优先级）

- [ ] 写到的技术，材料里有没有对应项目或经历支撑？
- [ ] 每个数字（比例、规模、时长、并发、性能）有没有来源？
- [ ] "精通/熟练掌握"与材料里体现的使用深度是否匹配？
- [ ] 获奖、排名、上线、签约等成果有没有可核验来源？

## B. 职责边界

- [ ] "参与/协助"有没有被写成"独立负责/主导"？
- [ ] 团队成果有没有被表述成个人成果？
- [ ] 职责范围是否超出了该阶段通常可能的范围？

## C. 表达质量

- [ ] 有没有只有形容词、没有动作和对象的 bullet？
- [ ] 同一件事是否在多个段落重复？
- [ ] 每一条能否看出"我做了什么、用什么、结果是什么"？

## D. 结构与完整度

- [ ] 基本信息、教育、经历、项目、技能是否齐备？
- [ ] 时间线是否连续，空档是否会在面试中被追问？
- [ ] 是否有与目标方向无关的堆砌？

## 输出格式

```text
问题：……
原文：……（quote 或 fact_id）
影响：……
建议：……（可执行动作，不是替用户写好的成品）
```

查无来源的一律写成：

```text
待核实：材料中未找到 xx 的依据，请补充或删除该说法。
```
