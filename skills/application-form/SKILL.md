# 按需填写企业官网网申表单

用户明确要求填写当前网申页面时，先读取当前绑定网页和字段，再检索当前 Candidate 所需事实，调用受控填写工具。普通职业对话不启动浏览器或填写申请。

默认保留一切已输入内容，数字 0、否、false 都是有效答案。扫描后用户刚输入的内容也要保留。checkbox 的未勾选或 indeterminate 外观都不能证明空白，可能是“否”或已有部分选择，因此保留并交人工；明确带未选状态的单选/下拉仍可填写布尔答案。字段句柄、页面或登录状态变化时重新扫描；不要猜测其他页面、账号或 Candidate。

资料来自当前 Candidate 的有效来源事实及用户明确填写的申请档案。姓名、联系方式、教育、项目、实习等需要真实来源；身份证、住址等敏感档案由服务直接注入浏览器，不读回聊天、工具结果或模型上下文。不把申请答案、JD 或助手文字自动写入 Candidate Facts。

采用 JEV 的决策方法：先确定目标和约束，区分事实与偏好，选择有证据支持的答案，未知或冲突时跳过对应字段。薪资、到岗时间、异地意愿只使用用户已确认的偏好。不要以“面议”“随时到岗”等默认值替代缺失信息。开放题使用主 Career Agent 起草，每条事实引用当前有效 factIds；不得编造公司、学校、技术、数字或扩张职责。

JEV 只参与受限的字段用途 Choice 判断：工具可以将固定公开用途词和控件类型发送给 jev-latest；姓名、联系方式、身份证、地址、个人答案、网页 URL 和任意原始标签不发给它。确定性常规映射不需要调用；缺少密钥、调用失败、低置信度或用途不明时，该字段留给人工。只按工具回传的 realJevCalled 和 decisionStatus 描述是否成功调用，不把采用协议说成真实调用。不增加第二个 Brain、Router 或自定义 agent loop；JEV 不生成事实、不批准写入或提交。

受控浏览器工具支持原生字段、明确 ARIA 绑定的单选/搜索下拉和同源嵌套 iframe。简道云使用独立站点适配器识别字段标签、子表列头、单选组、单选下拉、明确选项数组的多选、日期及附件；以本次扫描的 occupied/unsupported 和实际回读结果为准。多选使用用户明确提供的完整选项名称，不拆逗号猜选项；先核对整组选项，再逐项验证已有集合不被他人改变。跨源 iframe、尚未验证的级联、未知子表上传控件与下一页导航仍交人工。不要将部分支持描述成跨站通用全自动。

先 inspect_application 取得字段及 scanId，再检索当前候选人的来源事实。可通过 fill_application 的 scan_id 与 drafts_json 提供最多8个有来源的非敏感字段答案：JSON数组中每项含 fieldId、value、factIds；服务将再次核验事实状态、来源、字段类型和浏览器身份。教育字段只引用 education，实习字段只引用 experience，项目字段只引用 project。缺失身份/偏好不能用模型草稿绕过申请档案。补充资料仍是用户明确声明，不把助手生成的答案自动存成事实。

当前明确填写请求下可调用 ensure_application_rows 按已确认申请档案的经历条数补齐受控的教育/实习/项目/获奖/社团干部行，逐行验收；不从原文片段数量猜经历条数。获奖与社团使用各自已确认的结构化记录，不能挪用项目事实。不删除或替换已有行。增加后旧 scanId 失效，必须重新 inspect_application。每次添加/填写前都重新核验；本轮过程中网页联动或用户输入使字段变非空，也保留并列出待核对项。

每个批次先填当前能确定的字段，再汇总待处理项。缺失资料、没有对应选项或未支持的控件不是反复调用同一填写工具的理由。只有联动或补齐行使页面结构/选项发生变化时重新扫描并填写，最多两轮补充批次；仍待处理的集中交还用户。不为完成率编造资料或无限重试。用户明确限定一次填写调用时遵守这个次数。

附件必须由用户在网申面板逐个空白上传框明确选择当前 Candidate 的已上传原文件，再点击填写；聊天工具不替用户挑文件，不接受任意路径或文件内容。未选就保留手动上传，已有附件和扫描后新选的文件不替换。来源失效、文件变化、超过8MB总量或格式不符时不上传，原文件可能包含敏感资料且网页可能立即收到它。已适配的简道云获奖证明通过源行新打开的唯一上传弹层选择文件；弹层或输入框变化时停止。attachment_selected 仅表示原文件已选中，仍计待核对，不能称网站已接收或上传成功。

不要点击最终提交、发送、投递、隐私授权、电子签名或验证码按钮。页面可能在输入或失焦时自动保存资料；停在最终提交前不等于资料尚未外发。用户明确要求填写当前网页后直接执行，完成时集中列出未填项，不逐字段额外询问。

只依据工具真实回读状态报告成功：填写数量、保留数量、缺失资料、缺证据或不支持的控件。attachment_uploaded 表示已适配的普通简道云附件同时核对了本次原文件上传回执和原控件回显，单独报告 uploadedAttachments，不混入内容填写数。attachment_selected 仍需核对网站接收；证明弹层及未知上传链路不能借普通附件的成功状态升级。填写或模型失败时保留完成项，明确尚未完成的项，不伪装成完整成功。
